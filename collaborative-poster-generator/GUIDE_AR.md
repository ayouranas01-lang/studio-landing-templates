# دليل استخدام أداة Collaborative Poster Generator

## نظرة عامة

أداة Python لتحويل أي صورة إلى منتج تعليمي Collaborative Poster جاهز للبيع على منصة TPT (Teachers Pay Teachers).

تنتج الأداة نسختين:
- **نسخة بالألوان** — الصورة الأصلية مقسمة إلى مقاطع
- **نسخة أبيض وأسود** — للتلوين (خطوط فقط بدون ألوان)

---

## 1. تثبيت المتطلبات

تأكد من تثبيت Python 3.10 أو أحدث، ثم نفذ:

```bash
pip install -r requirements.txt
```

---

## 2. تحضير الصور

ضع صورتك (PNG أو JPG) في مجلد `input/`:

```
collaborative-poster-generator/
├── input/
│   ├── صورتك.png      ← ضع صورتك هنا
│   └── صورة_اخرى.jpg
```

**ملاحظات عن الصور:**
- الحد الأدنى المُوصى به: 1800×1200 بكسل (للطباعة بجودة عالية)
- صيغ مدعومة: PNG, JPG, JPEG
- يُفضل أن تكون الصورة بتنسيق أفقي (landscape)

---

## 3. تشغيل الأداة

### إنتاج النسختين معاً (ألوان + أبيض وأسود)

```bash
cd collaborative-poster-generator
python main.py -i input/صورتك.png -g 4x6 -t "Back to School" -m both --zip
```

### إنتاج نسخة الألوان فقط

```bash
python main.py -i input/صورتك.png -g 4x6 -t "Back to School" -m color
```

### إنتاج نسخة أبيض وأسود فقط

```bash
python main.py -i input/صورتك.png -g 4x6 -t "Back to School" -m bw
```

---

## 4. خيارات الأمر

| الخيار | الاختصار | الوصف | الافتراضي |
|--------|----------|-------|-----------|
| `--input` | `-i` | مسار الصورة المدخلة (مطلوب) | — |
| `--grid` | `-g` | حجم الشبكة: `3x6`, `4x6`, `5x6` | `4x6` |
| `--title` | `-t` | عنوان المنتج | `Collaborative Poster` |
| `--subtitle` | `-s` | العنوان الفرعي | `Collaborative Coloring Activity` |
| `--banner-text` | `-b` | نص الرايات (افتراضياً يستخدم العنوان) | — |
| `--mode` | `-m` | وضع الإنتاج: `color`, `bw`, `both` | `both` |
| `--output` | `-o` | مسار ملف PDF المخصص | تلقائي |
| `--zip` | — | تجميع الملفات في أرشيف ZIP | لا |

---

## 5. أحجام الشبكة

| الحجم | الصفوف × الأعمدة | عدد المقاطع |
|-------|-------------------|-------------|
| `3x6` | 3 × 6 | 18 مقطع |
| `4x6` | 4 × 6 | 24 مقطع |
| `5x6` | 5 × 6 | 30 مقطع |

---

## 6. المخرجات

بعد تشغيل الأمر، ستجد الملفات في مجلد `output/`:

```
output/
└── صورتك_4x6/
    ├── صورتك_4x6_color.pdf      ← النسخة الملونة
    ├── صورتك_4x6_bw.pdf         ← نسخة أبيض وأسود (للتلوين)
    └── صورتك_4x6_product.zip    ← ملف مضغوط (إذا استخدمت --zip)
```

### محتويات كل ملف PDF:

1. **صفحة الغلاف** — عنوان المنتج مع صورة مصغرة
2. **جدول المحتويات** — فهرس بأرقام الصفحات
3. **دليل التجميع** — خريطة الشبكة + تعليمات خطوة بخطوة
4. **صفحات المقاطع** — كل مقطع في صفحة مع خطوط القص والكود (A1, B2, ...)
5. **رايات Banner** — أعلام مثلثة للتزيين

---

## 7. مثال عملي كامل

```bash
# 1. ضع صورتك في مجلد input
cp ~/Downloads/earth_day_poster.png input/

# 2. شغل الأداة (النسختين + ZIP)
python main.py -i input/earth_day_poster.png -g 4x6 -t "Earth Day" -b "EARTH DAY" -m both --zip

# 3. ستجد الملفات في:
#    output/earth_day_poster_4x6/earth_day_poster_4x6_color.pdf
#    output/earth_day_poster_4x6/earth_day_poster_4x6_bw.pdf
#    output/earth_day_poster_4x6/earth_day_poster_4x6_product.zip
```

---

## 8. رفع المنتج على TPT

1. ارفع ملف ZIP على منصة TPT
2. أو ارفع ملفي PDF بشكل منفصل (نسخة ملونة + نسخة تلوين)
3. استخدم صفحة الغلاف كصورة معاينة للمنتج

---

## 9. استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| `No such file or directory` | تأكد أن الصورة موجودة في مجلد `input/` |
| `Grid must be one of` | استخدم أحد الأحجام: `3x6`, `4x6`, `5x6` |
| جودة الطباعة منخفضة | استخدم صورة بدقة 1800×1200 بكسل على الأقل |
